# مستقبل المهن XR 🚀

> **English:** An English version of this guide is available in [README.md](README.md).

معرض مهني افتراضي مستوحى من الواقع الممتد يعمل في المتصفح، مبني بمكتبة
**Three.js** (الواجهة الأمامية) وإطار **Flask** (الخادم الخلفي). يتجول
الزائر داخل مبنى مستقبلي، ويلتقي بالمساعد الذكي للإرشاد المهني
(«سعود»)، ويستكشف ثلاث غرف مهنية:

1. **هندسة الطاقة المتجددة**
2. **الذكاء الاصطناعي**
3. **الروبوتات الجراحية**

الواجهة بالكامل باللغة **العربية الفصحى الحديثة** وباتجاه **من اليمين
إلى اليسار (RTL)**، باستخدام خطي **Cairo** و**Tajawal** العربيين.

بُني المشروع كعرض توضيحي جامعي — دون Unity أو Unreal، ودون قاعدة بيانات
SQL؛ يعمل كلياً في متصفح الويب مع خادم بايثون خفيف.

---

## 1. المتطلبات

- **بايثون 3.9 أو أحدث**
- متصفح حديث (يُنصح بكروم أو إيدج أو فايرفوكس لدعم WebGL وقفل المؤشر)
- اتصال بالإنترنت عند أول تشغيل (تُحمَّل Three.js والخطوط من CDN)
- (اختياري) مفتاح **Groq المجاني** (من https://console.groq.com/keys — يبدأ بـ gsk_) إذا أردت توصيات ومحادثة مدعومة بنموذج لغوي حقيقي
  بدلاً من الوضع المحلي المدمج

لا حاجة لـ Node.js ولا npm ولا أي خطوة بناء.

## 3. التثبيت والتشغيل

```bash
cd FutureCareerXR/backend
pip install -r requirements.txt
python app.py
```

ثم افتح المتصفح على:

```
http://localhost:5000
```

أو انقر نقراً مزدوجاً على **`run_project.bat`** في ويندوز. ستظهر شاشة
التحميل ثم بطاقة البدء — انقر **«ادخل إلى المبنى»** للبدء (هذه النقرة
ضرورية لتفعيل النظر بالفأرة والصوت بحسب سياسات المتصفحات).

> **مهم:** يجب تشغيل المشروع عبر HTTP (وهو ما يفعله `app.py` تلقائياً).
> فتح `index.html` مباشرة من القرص سيمنع تحميل نماذج GLB بسبب قواعد
> أمان المتصفح.

## 5. الغرف المهنية الثلاث

| الغرفة | المعرّف | المحتوى |
|--------|---------|---------|
| هندسة الطاقة المتجددة | `renewable_energy` | نماذج GLB حقيقية: لوح شمسي، توربين رياح، وحدة بطاريات، محول كهربائي، غرفة تحكم + شاشة جدارية بصورة المحطة الفرعية |
| الذكاء الاصطناعي | `artificial_intelligence` | نماذج GLB حقيقية: روبوت، رف خوادم، مركبة ذاتية القيادة، نظارة واقع ممتد + شاشتان جداريتان (الشبكة العصبية ومحطات العمل) |
| الروبوتات الجراحية | `surgical_robotics` | غرفة عمليات روبوتية مستقبلية: روبوت جراحي، طاولة عمليات، إضاءة جراحية، شاشات طبية، كاميرا منظار، وحدة تحكم الروبوت، أدوات جراحية دقيقة |

غرفة **الروبوتات الجراحية** حلّت محل غرفة «المهن الطبية» السابقة بالكامل.
كل جهاز قابل للنقر ويفتح بطاقة معلومات عربية تعرض: الاسم، الغرض، كيف
يعمل، التطبيقات الواقعية، التطورات المستقبلية، والفرص المهنية. وفي كل
غرفة كشك **«الرؤية المستقبلية»** تعلوه خريطة المملكة العربية السعودية
ثلاثية الأبعاد الدوّارة (`saudi_arabia.glb`)، ويتناول اتجاهات المستقبل
بما فيها فرص رؤية السعودية 2030.

## 6. المساعد الذكي للإرشاد المهني («سعود»)

- تطرح «سعود» خمسة أسئلة اختيار من متعدد بالعربية حول الهندسة
  والروبوتات والتقنية الدقيقة والابتكار الصحي (عدّلها في
  `frontend/career_ai.js` — مصفوفة `QUESTIONS`).
- عند الإكمال تُرسل الإجابات إلى نقطة النهاية `/recommend`.
- **مع مفتاح Groq**: يسأل الخادم نموذج Google Groq (انظر `recommendation.py`
  و`prompts.py`) — يجيب النموذج بالعربية ويختار حصراً أحد المسارات:
  **هندسة الطاقة المتجددة**، **الذكاء الاصطناعي**، **الروبوتات الجراحية**.
- **دون مفتاح**: نظام تقييم موزون شفاف (`SCORING_RULES`) يعطي التوصية
  الثلاثية نفسها محلياً — يعمل العرض دائماً دون إنترنت أو رصيد API.
- في `career_ai.js` توصية احتياطية إضافية على جهاز الزائر إذا كان خادم
  Flask نفسه متوقفاً، فتتدرج التجربة بأمان في كل الطبقات.

**أسهل طريقة (مستحسنة):** افتح `backend/.env` وضع مفتاحك بعد `GROQ_API_KEY=` (يبدأ بـ gsk_)، احفظ، ثم شغّل `run_project.bat`. لا حاجة لأي متغيرات بيئة في الطرفية. لا تشارك ملف `.env`.

لربط مفتاح: `export GEMINI_API_KEY=your-key` (ماك/لينكس) أو
`set GEMINI_API_KEY=your-key` (ويندوز) قبل `python app.py`.
ويمكن اختيار النموذج عبر `GEMINI_MODEL` (الافتراضي `groq-2.5-flash`).
المفتاح يُقرأ على الخادم فقط ولا يصل إلى المتصفح إطلاقاً. عندها تتغير
شارة سعود من «الوضع المحلي» إلى «الوضع المتصل (GPT)».

## 7. نظام إدارة الأصول (`frontend/assets.js`)

كل النماذج ثلاثية الأبعاد والصور مُعلنة في سجل واحد:

- **`MODEL_MANIFEST`** — يربط كل جسم في الغرف بملف `.glb` مع
  `targetSize` (تحجيم تلقائي) و`rotY` (الاتجاه) و`yOffset` (الارتفاع).
  تُحمَّل النماذج بشكل غير متزامن عبر `GLTFLoader`؛ يُضبط حجم كل نموذج
  ويُحاذى مع الأرض وتُفعَّل ظلاله ويحل محل شكله البديل عند وصوله.
  **إذا فشل تحميل نموذج**: يبقى الشكل البديل ظاهراً، ويُطبع تحذير في
  وحدة تحكم المتصفح، ويستمر تحميل بقية الأصول.
- **`PERSPECTIVE_ICON_MODEL`** — نموذج `saudi_arabia.glb` المستخدم
  كأيقونة دوّارة فوق كل كشك «رؤية مستقبلية».
- **`OBJECT_IMAGES`** — الصور الحقيقية لبطاقات معلومات الأجسام.
- **`ROOM_POSTERS`** — الملصقات الجدارية / شاشات العرض الرقمية لكل غرفة
  (تُحفظ نسبة أبعاد الصور تلقائياً).

لإضافة نموذج جديد: ضع ملف `.glb` في المجلد المناسب داخل
`frontend/assets/models/` وأضف سطراً واحداً في السجل — دون أي تعديل على
كود المشهد.

## 8. الواجهة البرمجية (الخادم)

### `GET /careers`
قاعدة البيانات المهنية الكاملة بالعربية (الغرف الثلاث وكل المعروضات
وأقسام الرؤية المستقبلية).

### `GET /careers/<career_id>`
غرفة واحدة. المعرّفات الصالحة: `renewable_energy`،
`artificial_intelligence`، `surgical_robotics`.

### `POST /recommend`
الجسم: `{ "answers": ["تحديات البرمجة", ...] }` ← كائن توصية يتضمن
`recommended_career` و`recommended_career_id` و`reasoning`
و`suggested_majors` و`useful_skills` و`scores` و`mode`.

### `POST /chat`
الجسم: `{ "message": "...", "history": [...] }` ← `{ "reply", "mode" }`.
الوضع المحلي يتضمن ردوداً عربية جاهزة قائمة على الكلمات المفتاحية.

## 9. حل المشكلات

- **شاشة سوداء / لا شيء يُحمَّل**: افحص وحدة تحكم المتصفح (F12) —
  غالباً CDN مكتبة Three.js محجوب في شبكتك.
- **النماذج لا تظهر (تبقى الأشكال البديلة)**: تأكد من التشغيل عبر
  `python app.py` (بروتوكول HTTP) وليس بفتح ملف HTML مباشرة؛ راجع
  تحذيرات `[assets]` في وحدة التحكم.
- **النظر بالفأرة لا يعمل**: انقر مرة على المشهد ثلاثي الأبعاد مباشرة —
  تتطلب المتصفحات نقرة من المستخدم لتفعيل قفل المؤشر.
- **سعود تعرض «الوضع المحلي» دائماً**: هذا متوقع ما لم تضبط
  `GEMINI_API_KEY`. الوضع المحلي كامل الوظائف بتصميمه.
- **`ModuleNotFoundError: No module named 'flask'`**: نفّذ
  `pip install -r requirements.txt` داخل مجلد `backend/`.

## تشغيل المعرض على نظارة الواقع الافتراضي (Meta Quest وغيرها)

معيار WebXR لا يعمل إلا عبر اتصال آمن (HTTPS). المشروع يوفّر ذلك محلياً
دون الحاجة إلى أي نفق خارجي مثل ngrok:

1. شغّل `run_vr.bat` بدل `run_project.bat` (يفعّل HTTPS تلقائياً وينشئ
   شهادة محلية عند أول تشغيل).
2. اقرأ العنوان الذي يطبعه، مثل: `https://192.168.1.15:5000`
3. افتح المتصفح داخل النظارة (Meta Quest Browser) واكتب العنوان نفسه.
4. سيظهر تحذير أمني لأن الشهادة محلية موقّعة ذاتياً — اضغط
   **Advanced** ثم **Proceed**. (آمن تماماً: الاتصال لا يغادر شبكتك.)
5. اضغط زر «🥽 ادخل الواقع الافتراضي» أسفل الشاشة.

**شرط وحيد:** أن يكون الحاسب والنظارة على نفس شبكة الواي فاي.

مزايا هذه الطريقة على الأنفاق الخارجية: تعمل بلا إنترنت، وأسرع بكثير
(النماذج تُنقل عبر الشبكة المحلية)، والعنوان ثابت لا يتغير.
